Act as a Senior UI/UX Designer specializing in mobile-first web apps and Essentialism. I am building a personal Birthday Tracker app.

Your goal is to design a single-screen layout and provide Tailwind CSS styling guidelines. The core philosophy is "KISS" (Keep It Simple, Stupid). No unnecessary tabs, no complex dashboards. Just what matters.

Design Context & Requirements:

Viewport: Primarily used on mobile devices.

Structure: A sticky header showing today's date (Hebrew and Gregorian). The body is a single continuous scrolling list of upcoming birthdays. A Floating Action Button (FAB) at the bottom right for adding a new record.

Card Design: Each person in the list is a clean card. It must show: Name, Birthday Date (Hebrew/Gregorian or both), Age turning, and a highly visible "Days Left" indicator.

Visual Hierarchy: The closest birthdays should be visually prominent. As the user scrolls down to birthdays that are months away, the visual weight can be slightly softer.

Theme: Provide a modern, sleek color palette. I prefer a clean iOS-like aesthetic or a polished Dark Mode interface. It should feel "sexy" and modern, not like a boring spreadsheet.

Deliverables: Describe the layout, spacing, typography, and provide specific Tailwind CSS class combinations for the main components (Header, Birthday Card, FAB, and Add Modal).
